# 데모 모드 (4.6.4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. 스펙·게이트 중심(디자인 반복 포함).

**Goal:** 연결 전 제품 체험용 공개 데모 — Shopify·Instagram·Meta·GA4 **통합 대시보드** + **어드밴스드** + **크로스플랫폼** 뷰를 현실적 샘플 데이터로 보여주고, 랜딩에서 진입시킨다. 영업·온보딩 전환용(마스터 플랜 4.6.4).

**Architecture:** 시드 고정 PRNG(mulberry32) 기반 결정적 샘플 데이터 모듈(`lib/demo/data.ts`)이 **크로스채널 상관관계를 내장**한 90일 데이터를 생성(IG 바이럴 → 세션 → 매출 시차, 광고 스파이크 → 매출 리프트, 주말 시즌성). 페이지는 인증 없는 서버 컴포넌트(정적 렌더 가능) + 기존 차트 키트. 신규 차트 조각: Heatmap(요일×시간·코호트), StackBar(구성).

**Tech:** 기존 `components/charts/` 키트 재사용 · KRW(`fmtCurrency('KRW')`) · 카피는 쉬운 한국어(Toss 공식, API 용어 금지) · Hume 토큰만.

## 데이터 스토리 (상관관계 = 제품 가치 시연)

- 가상 뷰티 D2C "글로우랩" · 90일 · 일 매출 ~₩2.8M, 성장 추세 +20%, 주말 -25%
- Meta 캠페인 5개(1개는 저효율 — 정직한 데모), 6주차 스파이크 → 매출 +1일 시차 리프트
- IG 바이럴 게시물 2회(35일·71일) → 도달 스파이크 → GA4 세션 동일일 → 매출 +1~2일
- 재구매율 ~28%, 코호트 리텐션 감쇠, 저녁 21–23시 피크(요일×시간)
- 인사이트 카드 5종: 콘텐츠→매출 · 광고 피로 · 재구매 적기 · 주말 전환율 · 재고 임박
